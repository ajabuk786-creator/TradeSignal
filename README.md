# TradeSignal Android

Small Android signal assistant for BTCUSDT 15m.

- Manual scan from Binance public klines
- EMA20/EMA50 + RSI pullback/reclaim + ATR stop
- Entry / Stop Loss / Take Profit at 1:2 R:R
- Does not place trades automatically
- Demo/test before using real money

GitHub Actions builds `app-debug.apk` as the artifact `TradeSignal-APK`.
